# ToDoList en TypeScript


## Especificaciones

Sedesea crear un toDoList para gestionar las tareas en TypeScript
Se debe tener en cuenta lo siguiente:

- Prohibido usar push, slice, splice, sort.
- Las tareas tienen las prioridades: low, medium, high
- De una tarea necesitamos: id, title, prioridad, un check para saber si esta completada o no: done

### Métodos a ejemplificar

- createTask
- toggleDone
- rename
- removeDone
- editTask
- pendingByPriority

Crear por tanto un main.ts en la carpeta toDoList que permita ejemplificar una app de tareas.
